How to Use VoiceTriage

1
Choose Input Mode
Switch between Text (type/paste), Audio (upload WAV/MP3), or Demo (pre-built synthetic cases).
2
Provide Patient Description
Type the patient's complaint in any Indian language or English. Use quick sample chips to try preset cases.
3
Select Language
Choose the language of the input so the system can correctly process regional terms.
4
Click Run Triage
The AI runs all 4 pipeline stages: Speech → NLP → RAG → Decision. Takes ~2–8 seconds.
5
Read the Result
The dashboard shows urgency level (🔴 Emergency / 🟡 Urgent / 🟢 Routine), specialist, confidence score, extracted symptoms, and a plain-language reason.
6
Use the Decision
Hand the result to the call-centre operator. The AI assists — the doctor always makes the final call.
7
View History & Stats
Click History to see all previous triages. Click Stats for urgency distribution and confidence metrics.
⚕️ Scope: This tool is for pre-call triage routing only. It does not diagnose or prescribe treatment.
